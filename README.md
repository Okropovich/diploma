# Веб-приложение для публикации и управления объявлениями (Дипломный проект)

Полнофункциональное веб-приложение для управления объявлениями, разработанное в рамках дипломного проекта. Проект реализует полный цикл работы с пользователями, объявлениями и комментариями с разграничением прав доступа.

## Стек технологий
* **Java 17**
* **Spring Boot 3**
* **Spring Security** (Аутентификация и авторизация, роли USER / ADMIN)
* **Spring Data JPA & Hibernate**
* **PostgreSQL** (Реляционная база данных)
* **Liquibase** (Управление миграциями БД)
* **SpringDoc OpenAPI / Swagger** (Документация API)
* **Maven** (Сборка проекта)

---

## Архитектура проекта (Слоистая структура)
Проект построен по классической многослойной архитектуре (Layered Architecture):
1. **Controller (Слой представления):** Обрабатывает входящие HTTP-запросы, возвращает данные (REST API).
2. **Service (Бизнес-логика):** Содержит основные алгоритмы, проверки безопасности, валидацию и связывание данных.
3. **Repository (Слой данных):** Интерфейсы Spring Data JPA для взаимодействия с базой данных PostgreSQL.
4. **Entity / DTO:** Сущности базы данных и объекты передачи данных между слоями.
